# 西宮市体育館予約空き状況チェッカー

西宮市の施設予約システム（スポーツネットにしのみや）を自動巡回し、特定の条件で体育館の空きが見つかった場合にメールで通知するスクリプトです。GitHub Actions を利用して定期的に実行することができます。

## 🔍 チェック対象
- **対象体育館**: 今津、鳴尾、甲武、北夙川、流通東、松原
- **対象設備**: 体育室半面
- **対象時間帯**: 08:00 〜 18:00（デフォルト）
- **対象日**: 土曜日、日曜日、祝日（デフォルト）

## 🚀 セットアップ方法

### 1. リポジトリの準備
本プロジェクトを GitHub のプライベートリポジトリとして作成し、コードをプッシュしてください。

### 2. 通知用メールの設定 (GitHub Secrets)
リポジトリの `Settings > Secrets and variables > Actions > Secrets` に以下の値を設定してください。

| 名前 | 説明 | 例 |
| :--- | :--- | :--- |
| `EMAIL_USER` | 送信元 Gmail アドレス | `your-name@gmail.com` |
| `EMAIL_PASS` | Gmail アプリパスワード | `abcd efgh ijkl mnop` |
| `EMAIL_TO` | 通知先メールアドレス | `recipient@example.com` |
| `SMTP_HOST` | SMTP サーバー | `smtp.gmail.com` |
| `SMTP_PORT` | SMTP ポート | `465` |

> [!TIP]
> **Gmail アプリパスワードの取得方法**:
> 1. Google アカウントの「セキュリティ」から「2段階認証プロセス」を有効にする。
> 2. 「アプリパスワード」を検索し、新規作成して発行された 16 桁のコードを使用します。

### 3. チェックしたい日時の指定 (GitHub Variables)
リポジトリの `Settings > Secrets and variables > Actions > Variables` に設定します。

| 名前 | 説明 | 例 |
| :--- | :--- | :--- |
| `TARGET_DATES` | 特定の日付や時間帯の指定 | `2026-04-11:10-14, 2026-04-12` |

- **空欄の場合**: 全ての土日祝日の 08:00-18:00 をチェックします。
- **日付のみ指定**: その日の 08:00-18:00 をチェックします。
- **日付と時間を指定**: `日付:開始時-終了時` の形式で、特定の時間帯のみを狙い撃ちできます。

## 📅 実行タイミング
- **自動実行**: 毎日 **07:00 〜 21:00 の間、30分おき** に自動でチェックが走ります。
- **手動実行**: GitHub の `Actions` タブから `Reserve Check` ワークフローを選択し、`Run workflow` をクリックすることで即時実行可能です。

## 🛠️ ローカルでの開発・テスト

```bash
# 依存関係のインストール
npm install

# ブラウザのインストール
npx playwright install chromium

# テスト実行（環境変数をセットして実行）
EMAIL_USER=... EMAIL_PASS=... EMAIL_TO=... npm run check
```
